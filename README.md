# NEO-REFUTE: Multimodal Fake News Detection System

## 📌 Project Overview

NEO-REFUTE is a Final Year Team Project developed to detect fake news using Artificial Intelligence, Natural Language Processing (NLP), and Multimodal Deep Learning. The system analyzes both textual and visual information to classify news as **Real**, **Fake**, or **Uncertain**.

The project combines semantic text analysis, source credibility evaluation, image-text consistency checking, and uncertainty-aware prediction to improve fake news detection. :contentReference[oaicite:1]{index=1} :contentReference[oaicite:2]{index=2}

## 🚀 Features

- Fake News Detection using Transformer-based NLP
- Image and Text Consistency Analysis
- Source Credibility Evaluation
- Historical Pattern Recognition

- Confidence-based Prediction

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/divyanshugupta1209-glitch/Fake-news-Detection.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

or

```bash
uvicorn main:app --reload
```
